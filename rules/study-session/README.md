# Focus Session

Start a scheduled study session on Mac by opening Chrome, a research page and a folder, then show a reminder after 45 minutes.

The example uses a weekly 9:00 schedule, Google Scholar and a Focus folder. Change the schedule, URL and folder to suit your study routine.

## How this Rule works

The example uses a weekly 9:00 schedule, Google Scholar and a Focus folder. Change the schedule, URL and folder to suit your study routine.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

Chrome and the selected folder must be available. The delay and notification do not block distractions or track active study time.
