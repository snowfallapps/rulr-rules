# Reveal Renamed Files

Reveal a newly added file from a watched Mac folder in Finder.

The current Trigger is configured for added items in Downloads, and passes the item path to Reveal File. Choose the watched folder and change the event to Renamed if that is your goal.

## How this Rule works

The current Trigger is configured for added items in Downloads, and passes the item path to Reveal File. Choose the watched folder and change the event to Renamed if that is your goal.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

Folder monitoring requires Pro and access to the selected folder. The default reacts to additions, not renames; test with a disposable file.
