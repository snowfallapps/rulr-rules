# Sort Project Files

Sort newly added files in a watched Mac folder into separate destinations by filename.

The default watches Downloads: PDF files go to Documents, image extensions to Pictures, and ZIP files to Downloads/Archives. Choose your own source and three destinations before enabling it.

## How this Rule works

The default watches Downloads: PDF files go to Documents, image extensions to Pictures, and ZIP files to Downloads/Archives. Choose your own source and three destinations before enabling it.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

Folder monitoring and Move File require Pro and folder access. Only matching new items are handled; existing files and unmatched names are not organized. Test with disposable copies.
