# Transform and Archive Notes

Normalize line endings in new text files in a watched Mac folder, then move those files to an archive.

For a newly added name ending in `.txt`, the Rule reads the file, normalizes line endings, overwrites its contents and moves it to the selected archive. Choose separate inbox and archive folders.

## How this Rule works

For a newly added name ending in `.txt`, the Rule reads the file, normalizes line endings, overwrites its contents and moves it to the selected archive. Choose separate inbox and archive folders.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

Folder monitoring, text processing, writing and moving require Pro and folder access. This overwrites and moves the original; test on disposable copies and keep backups.
