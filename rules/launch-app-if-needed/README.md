# Launch App

Launch a chosen Mac app with a keyboard shortcut.

The example uses Option-Space to launch Safari with no Condition. Select your app and an unused shortcut in the Rule.

## How this Rule works

The example uses Option-Space to launch Safari with no Condition. Select your app and an unused shortcut in the Rule.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

Allow Accessibility for the shortcut and test with the app closed and already running. This sample contains Launch Application only; it does not include a separate focus Action.
