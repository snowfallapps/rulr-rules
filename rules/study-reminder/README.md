# Review Reminder

Set a repeating study reminder on Mac during a chosen time window. The Rule shows a notification and speaks a short reminder at each interval.

The sample runs every 30 minutes from 9:00 to 17:00. Adjust the interval, active hours, and message after importing.

[Website preview and full setup](https://www.rulr.app/rules/repeat-study-reminder-mac/) · [Download study-reminder.rulr](https://github.com/snowfallapps/rulr-rules/raw/HEAD/rules/study-reminder/study-reminder.rulr) · [All rules](../../README.md)

on the linked website page. Review permissions and app-specific settings before
enabling the Rule. The instructions below refer to Rulr and that detail page.

## How this Rule works

The Interval Trigger starts the notification and Speak Text Actions without a Condition. The sample notification says the Rule ran successfully, while the spoken text is `Review Reminder`; edit both messages to make them useful for your routine.

## Configure and try it

Set the interval and active hours, edit the notification and spoken text, and allow Notifications. Enable the Rule and check a scheduled occurrence with the Mac awake.

## Requirements and limits

Speak Text requires Rulr Pro. Notification delivery depends on macOS notification settings. The Rule does not inspect your notes or determine whether you have completed a review.
