# Project Drive

Open a mounted volume on Mac when the system detects it.

The volume-mounted Trigger supplies the mounted volume path to Open File or Folder. It has no Condition and does not select a particular drive by default.

## How this Rule works

The volume-mounted Trigger supplies the mounted volume path to Open File or Folder. It has no Condition and does not select a particular drive by default.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

Grant access to the volume if macOS asks. Test by mounting a disposable volume; add a suitable filter if you only want a specific drive.
