# Open Research Drive

Open a chosen Mac folder and show a notification when a volume mounts.

Any volume mount triggers Open File or Folder and a notification. The sample opens Downloads; select your research folder and adjust the notification before use.

## How this Rule works

Any volume mount triggers Open File or Folder and a notification. The sample opens Downloads; select your research folder and adjust the notification before use.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

The Rule does not filter for a particular drive or verify that the folder belongs to the mounted volume. Grant folder access if requested and test with a mounted volume.
