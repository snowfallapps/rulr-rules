# Capture Reading Pages

Append the active Chrome tab URL to a text file when a window title changes on Mac.

The Trigger watches focused-window title changes; the Rule reads the current Chrome tab and appends its URL to the configured file. Choose a log file before enabling it.

## How this Rule works

The Trigger watches focused-window title changes; the Rule reads the current Chrome tab and appends its URL to the configured file. Choose a log file before enabling it.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

The title-change Trigger, Chrome integration and file writing require Pro; Chrome Automation and file access may be needed. Changes in other apps can also trigger the Rule, and repeated URLs are possible.
