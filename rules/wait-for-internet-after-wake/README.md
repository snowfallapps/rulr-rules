# Resume Work

After a Mac wakes, wait for a network connection and open different work tools based on the Wi-Fi name.

The Rule waits up to two minutes for connectivity, then checks separate Office and Home network conditions. The example opens Slack and Google Calendar for Office, or Notion and its website for Home.

## How this Rule works

The Rule waits up to two minutes for connectivity, then checks separate Office and Home network conditions. The example opens Slack and Google Calendar for Office, or Notion and its website for Home.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

Replace both example network names, apps and URLs, then test each branch. A different network matches neither branch; the example does not restore previous windows or browser sessions.
