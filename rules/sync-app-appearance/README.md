# Sync App Appearance

Pass the new system appearance to an AppleScript when the Mac appearance changes.

The example script returns the appearance argument; it does not change another app. To synchronize an app, replace it with a reviewed script supported by that app.

## How this Rule works

The example script returns the appearance argument; it does not change another app. To synchronize an app, replace it with a reviewed script supported by that app.
