# Save Screen Capture

Capture the full Mac screen with a shortcut and move the resulting file to a selected folder.

Option-Space captures the full screen; Move File uses the capture file path and defaults to Downloads. Select an unused shortcut and destination.

## How this Rule works

Option-Space captures the full screen; Move File uses the capture file path and defaults to Downloads. Select an unused shortcut and destination.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

Move File requires Pro; allow Accessibility, Screen Recording and destination-folder access as requested. The sample moves the capture and uses numbered names on conflicts.

To choose a meaningful filename immediately after capturing a region, use [Capture and Name Screenshot](https://www.rulr.app/rules/screenshot-macro-mac/). It asks for a name and saves the PNG in your configured destination, initially Downloads.
