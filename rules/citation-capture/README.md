# Citation Capture

Use a typed phrase to append a Chrome page title, URL and selected text to a citation file on Mac.

The default phrase is `;cite`; the Rule reads the current Chrome tab and selection, then appends the assembled citation to a text file. Choose a phrase and an accessible destination file.

## How this Rule works

The default phrase is `;cite`; the Rule reads the current Chrome tab and selection, then appends the assembled citation to a text file. Choose a phrase and an accessible destination file.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

The typed trigger, Chrome integration and file writing require Pro. Allow Accessibility and Chrome Automation access, then test with a short selected quote. The phrase may affect selection or focus in some editors.
