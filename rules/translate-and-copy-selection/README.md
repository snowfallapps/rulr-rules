# Translate and Copy

Use a shortcut to translate selected text on Mac and put the translation on the clipboard.

Option-Y reads the selection, translates it to English and replaces the clipboard with the translated text. Choose a different shortcut or target language in the Rule.

## How this Rule works

Option-Y reads the selection, translates it to English and replaces the clipboard with the translated text. Choose a different shortcut or target language in the Rule.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

Allow Accessibility for the shortcut and selection, and verify translation availability for your language. Existing clipboard contents will be replaced.
