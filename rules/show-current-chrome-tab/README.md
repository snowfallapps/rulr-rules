# Show Current Tab

Show the active Google Chrome tab URL in a panel with a keyboard shortcut on Mac.

Option-Space retrieves the current Chrome tab and sends its URL to Show Content. Change the shortcut if it conflicts with another app.

## How this Rule works

Option-Space retrieves the current Chrome tab and sends its URL to Show Content. Change the shortcut if it conflicts with another app.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

The Chrome integration requires Pro and Chrome Automation permission; the shortcut requires Accessibility. Chrome must have an accessible active tab. This displays the URL rather than copying it.
