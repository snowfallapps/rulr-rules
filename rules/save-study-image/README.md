# Capture Image

Capture the screen as a PNG on Mac by typing a trigger. The Rule captures the full screen, converts the image, and copies it to a selected folder.

The sample uses the exact typed phrase `;screenshot` and a Screenshots folder in Documents. Choose a phrase and destination that suit your workflow.

## How this Rule works

Text Typed starts a full-screen capture. Convert Image produces PNG, and Copy File copies the result to the selected folder, using a numbered name if needed. There is no Condition.

## Configure and try it

Choose an uncommon typed phrase and a writable destination folder. Grant Accessibility and Screen Recording permissions, enable the Rule, type the phrase in a normal text field, and check the PNG in the destination.

## Requirements and limits

Text Typed and Convert Image require Rulr Pro. The sample captures the full screen; it does not select a region or extract text. Change the capture target if you need a different capture.
