# Set Up Headset Audio

When a matching Bluetooth device connects to your Mac, switch audio output and set its volume.

The example checks whether the connected device name contains AirPods, then runs Switch Audio Output Device and Set Volume at 35%. Set the name match and review the output Action in the editor.
