# Recognize Screen Text

Press a shortcut to recognize text on the full Mac screen and show the result in a panel.

Option-Space starts full-screen recognition and displays the OCR output. Change the shortcut or capture target if needed.

## How this Rule works

Option-Space starts full-screen recognition and displays the OCR output. Change the shortcut or capture target if needed.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

Grant Accessibility for the shortcut and Screen Recording access for capture. Recognition depends on visible text; this Rule displays the result rather than copying it automatically.
