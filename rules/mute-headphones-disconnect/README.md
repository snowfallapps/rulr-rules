# Mute Disconnected Headphones

Run the Mac audio mute Action when a matching Bluetooth headset disconnects.

The Bluetooth disconnect Trigger checks whether the device name contains AirPods, then runs Mute or Unmute Audio. Change the match to your headset name.

## How this Rule works

The Bluetooth disconnect Trigger checks whether the device name contains AirPods, then runs Mute or Unmute Audio. Change the match to your headset name.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

The Action has no explicit mode in this sample; check its default in the editor before assuming it always mutes. Test at a safe volume.
