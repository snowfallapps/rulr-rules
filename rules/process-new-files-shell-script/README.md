# Process New Files

Pass a newly added file path to a shell script and show a success notification on Mac.

The folder Trigger passes the item path as the first script input. The supplied example prints that input and does not modify the file; select a folder and write your own script for additional processing.

## How this Rule works

The folder Trigger passes the item path as the first script input. The supplied example prints that input and does not modify the file; select a folder and write your own script for additional processing.

## Configure and try it

Import the Rule, review its Trigger and Actions, and adjust the settings described above before enabling it. Test the result in a safe, temporary context.

## Requirements and limits

Folder monitoring and Run Shell Script require Pro. Review and test any replacement script on disposable files. The notification follows successful script execution, not independent verification of a file transformation.
